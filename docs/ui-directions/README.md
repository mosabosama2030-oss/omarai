# Omarai — Three Glass UI Directions

**Status:** Visual proposals for Human Director selection only. No direction is implemented or connected to production APIs.

Design project: https://design.agent-native.com/design/sGSw7-l6baKesddSGTdvl?editorView=overview

## Option 01 — Aurora Glass
- Expressive frosted surfaces with teal/cyan/violet ambient glow.
- Futuristic, colorful Android-inspired atmosphere with restrained layering.
- Best when the product should feel distinctly modern and visually memorable.
- Preview: [variant-01-aurora-glass.html](variant-01-aurora-glass.html)

## Option 02 — Precision Glass
- Restrained graphite glass, generous spacing, soft blue accent, evidence-first hierarchy.
- Apple-inspired calm spatial depth without copying platform UI.
- Best for sustained daily use, readability, and professional trust.
- Preview: [variant-02-precision-glass.html](variant-02-precision-glass.html)

## Option 03 — Neon Command
- Compact command-center layout with navy surfaces and cyan/indigo luminous edges.
- Strong operational hierarchy and denser information display.
- Best for power users monitoring multiple market signals and qualification stages.
- Preview: [variant-03-neon-command.html](variant-03-neon-command.html)

## Shared design requirements
- Arabic-first RTL; Noto Sans Arabic / IBM Plex Arabic system fallback.
- Responsive desktop and mobile layouts with CSS breakpoints.
- Evidence source/date and human-review status remain visible.
- Demo records are illustrative and explicitly labeled.
- No fabricated purchase probability, contact details, or real-world claims.
- Static prototypes only: no production APIs, authentication, or backend behavior.

## Approval gate
Human Director selects one direction. Only after selection should the chosen visual direction be refined and implemented against Omarai's existing session/lead API contracts. The other two remain archived proposals. No merge or deployment is authorized by this PR.
