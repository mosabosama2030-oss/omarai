# دليل تشغيل Omarai

## التشغيل
من مجلد المشروع شغّل:
```bash
python -m cli.omarai serve
```
ثم افتح `http://127.0.0.1:8765` في المتصفح على الهاتف نفسه. أوقف الخادم بـ Ctrl+C.

## سير العمل

يمكنك كذلك استخدام مربع «اسأل Omarai» لطلب إحصائيات السجل المحلي أو ترشيح إشارة للمراجعة أو تفسير الدرجة أو صياغة مسودة تواصل. الإجابات مبنية على قواعد محلية وسجلات محفوظة فقط؛ لا يوجد نموذج سحابي ولا تُرسل أي رسالة تلقائيًا.

1. أدخل نصًا من مصدر عام أو مصدر لديك إذن باستخدامه.
2. اضغط «حلّل الإشارة» وافحص العبارات المطابقة وسبب النقاط.
3. أضف رابط المصدر الحقيقي قبل الحفظ.
4. راجع الإشارات يدويًا وغيّر الحالة إلى مؤهل أو يحتاج مراجعة أو غير ذلك.
5. صدّر CSV عند الحاجة واحتفظ بنسخة احتياطية آمنة.

## قواعد مهمة
- لا تدخل رسائل خاصة أو بيانات اعتماد أو أرقام هواتف غير لازمة.
- لا تعتبر الدرجة احتمالًا للشراء.
- لا يتصفح Omarai المنصات تلقائيًا ولا يرسل رسائل.
- الخادم مربوط بعنوان loopback افتراضيًا، ويرفض أنواع المحتوى غير JSON والطلبات ذات Origin غير محلي. لا تكشفه للشبكة أو الإنترنت دون مصادقة واختبار أمني.
- قاعدة البيانات الافتراضية: `~/.omarai/omarai.sqlite3`.
