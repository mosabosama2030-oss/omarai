## ما لا يُعد مكتملًا رغم نجاح CI

هذه الحدود لا يمكن إغلاقها بنتائج Pytest أو Docker وحدها:

| المجال | الحالة | معيار الإغلاق |
|---|---|---|
| Hosted smoke إلى خدمة منشورة فعلية ومطابقة SHA | `NOT_RUN` | مضيف HTTPS مُعتمد، الأسرار في بيئة آمنة، نجاح health/auth/diagnostics ومطابقة SHA |
| موفرو البحث والنموذج الحيون | `NOT_RUN / UNKNOWN` | فحص كل موفر مفعّل على البيئة المستهدفة بوقت/تكلفة موثّقين |
| التقييم الدلالي لحالات AQ-001–045 | `PARTIAL / LIVE QUALITY NOT_RUN` | تنفيذ المعيار على الإجابات الفعلية مع مراجع موثقة ومراجعة بشرية للأحكام |
| Volume دائم وSQLite backup/restore على مضيف فعلي | `NOT_RUN` | إثبات بقاء السجل بعد إعادة التشغيل/النشر، ثم استعادة نسخة احتياطية ناجحة |
| اختبار الحمل والـrate limit الموزع | `NOT_RUN` | قياسات قابلة للتكرار، مع زمن الاستجابة والأخطاء والموارد والتزامن |
| Prompt-injection red-team مستقل وحي | `PARTIAL / NOT_RUN` | مصفوفة هجمات ومراجعة نتائج مستقلة في بيئة مخولة |
| تعدد المستأجرين وعزل بياناتهم | `NOT_REQUIRED للنطاق الحالي؛ BLOCKER للتوسع العام` | هوية وصلاحيات وملكية سجلات واختبارات عزل قبل خدمة عدة عملاء |
| تقرير Grok المستقل الكامل | `UNKNOWN` | تقرير فعلي قابل للوصول مرتبط بـSHA وأدلة ونتائج قابلة للمراجعة |
