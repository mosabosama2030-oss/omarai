# نشر Omarai على Vercel Hobby (المستوى المجاني)

هذا الدليل مخصص لنشر **عرض شخصي** على خطة Vercel Hobby المجانية فقط.
لا يفعّل أي خطة مدفوعة ولا أي واجهة برمجة مدفوعة.

## ما الذي يعمل فعليًا

- واجهة البحث العربية (RTL) على `/` و `/agent`
- مساحة العملاء المحلية على `/leads` (تخزين SQLite **غير دائم** على Vercel)
- نقاط API: `/api/health`، `/api/agent`، `/api/diagnostics`، وواجهات العملاء
- المصادقة عبر `OMARAI_ACCESS_TOKEN`
- البحث العام + توليد الإجابة عبر نماذج مجانية قابلة للتهيئة على OpenRouter

## قيود المستوى المجاني (Hobby)

| البند | الواقع |
|--------|--------|
| مدة التنفيذ القصوى | حتى 300 ثانية لكل طلب (Fluid compute) |
| التخزين | نظام الملفات مؤقت؛ قاعدة SQLite تُعاد عند كل استدعاء بارد |
| النوم | الاستدعاءات الباردة قد تستغرق ثوانٍ إضافية |
| الأسرار | يجب إدخالها من لوحة Vercel فقط، لا تُرفع إلى GitHub |
| النماذج | المعرفات الافتراضية مجانية وقد تتغير أو تنفد حصتها في أي وقت |

**لا تعتمد على سجل العملاء المحفوظ كبيانات دائمة على هذا النشر.**

## المتطلبات قبل البدء

1. حساب GitHub يملك المستودع.
2. حساب Vercel على خطة **Hobby** (مجانية). لا تختر Pro ولا تُدخل بطاقة للدفع.
3. مفتاح OpenRouter خاص بك (`OPENROUTER_API_KEY`).
4. رمز وصول عشوائي للتطبيق بطول 32 حرفًا على الأقل (`OMARAI_ACCESS_TOKEN`).

توليد الرمز محليًا (لا تلصقه في الدردشة العامة):

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

## خطوات النشر بالترتيب

1. سجّل الدخول إلى [vercel.com](https://vercel.com) بحساب Hobby.
2. **Add New Project** → **Import** المستودع `mosabosama2030-oss/omarai`.
3. اختر الفرع الذي يحتوي إعداد Vercel (مثلاً `grok/vercel-free-demo-20261015` أو `main` بعد الدمج).
4. اترك إعدادات البناء الافتراضية (Vercel يكتشف Python + `vercel.json`).
5. في **Environment Variables** أضف فقط:
   - `OMARAI_PUBLIC_DEPLOYMENT` = `1`
   - `OMARAI_ACCESS_TOKEN` = الرمز الذي ولّدته (Secret)
   - `OPENROUTER_API_KEY` = مفتاحك (Secret)
6. تأكد أنك لم تفعّل أي إضافة مدفوعة ولا خطة Pro.
7. اضغط **Deploy**.
8. بعد النجاح افتح الرابط العام الذي يظهر (مثل `https://….vercel.app`).
9. اختبر الصحة: افتح `/api/health` — يجب أن ترى `"ok": true`.
10. افتح الصفحة الرئيسية، أدخل رمز التطبيق في حقل الرمز داخل الواجهة.
11. شغّل التشخيصات من الواجهة.
12. اسأل سؤالًا عربيًا يحتاج معلومة حالية من الويب، وتحقق من ظهور الروابط المصدرية.

إذا طلب الموقع إدخال بطاقة دفع أو الترقية إلى Pro: **توقف فورًا** وارجع إلى خطة Hobby.

## بعد كل تحديث على GitHub

- ادفع التغييرات إلى الفرع المتصل.
- Vercel يعيد النشر تلقائيًا.
- لا تغيّر الأسرار في الكود؛ غيّرها فقط من لوحة Environment Variables.

## التشغيل المحلي (Termux / سطح المكتب)

```bash
python -m pip install -e ".[dev]"
export OMARAI_PUBLIC_DEPLOYMENT=0   # أو 1 مع رمز طويل للاختبار
# أدخل المفتاح دون حفظه في السجل إن أمكن
read -r -s -p "OpenRouter API key: " OPENROUTER_API_KEY; printf '\n'; export OPENROUTER_API_KEY
python -m cli.omarai serve
```

ثم افتح `http://127.0.0.1:8765`.

## إعادة تشغيل الاختبارات

```bash
python -m pip install -e ".[dev]"
ruff check agents api cli tests
python -m pytest -q
```

## خصوصية وتنويه

- يُرسل نص السؤال والسياق ومقتطفات الصفحات إلى مزوّد النموذج الخارجي (OpenRouter).
- النماذج المجانية قد تُسجَّل لأغراض الأمان وتحسين المنتج حسب سياسة المزوّد.
- لا ترسل كلمات مرور أو بيانات شخصية حساسة عبر نقطة النهاية المجانية.
- الوكيل لا يتجاوز جدران الدخول أو جدران الدفع ولا يرسل رسائل غير مرغوبة.

## استكشاف الأعطال بدون كشف الأسرار

| العرض | إجراء مقترح |
|--------|-------------|
| 401 | تأكد من إدخال `OMARAI_ACCESS_TOKEN` نفسه في الواجهة وفي أسرار Vercel |
| 429 | انتظر دقيقة؛ الحد الافتراضي 20 طلبًا/دقيقة لكل عنوان IP |
| 504 / مهلة | السؤال معقّد جدًا أو المزوّد بطيء؛ جرّب سؤالًا أقصر أو أعد المحاولة |
| إجابة بدون مصادر | البحث أو الاستخراج فشل؛ الرسالة يجب أن توضّح نقص الأدلة |
| SQLite فارغ بعد إعادة النشر | متوقع على Vercel؛ التخزين غير دائم |

هذا النشر مخصّص للعرض الشخصي والتحقق، وليس لاستضافة إنتاجية عالية التوافر.
