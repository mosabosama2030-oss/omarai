# دليل البحث المتقدم والموصلات الاجتماعية — Omarai

هذا الدليل يشرح ما يستطيع Omarai الوصول إليه فعلًا، وما يحتاج إلى مفاتيح وصلاحيات، وكيفية إعدادها من Termux. لا توجد طريقة شرعية أو تقنية مضمونة للوصول إلى كل منشورات كل منصة: بعض البيانات تتطلب مراجعة تطبيق وصلاحيات، وبعضها لا يظهر إلا في البحث المفهرس.

## 1. كيف يجري Omarai البحث؟

1. يفهم السؤال ويخطط حتى خمسة استعلامات بحث، باستخدام النموذج اللغوي إذا كان مفتاحه مضبوطًا؛ وإلا يستخدم خطة احتياطية محددة.
2. يبحث في DuckDuckGo HTML وBing RSS لكل استعلام، ويستخدم موجز Google News للأسئلة التي تبدو حديثة.
3. إذا كان السؤال اجتماعيًا، يجرّب المصادر العامة المتاحة والموصلات الرسمية التي أُعدّت بياناتها.
4. يزيل النتائج المكررة ويجمع تكرار ظهور المصدر عبر الاستعلامات ومحركات البحث مع الاحتفاظ باسم الموفر والاستعلام ورابط المصدر.
5. يحاول قراءة النص من أفضل خمس صفحات عامة على الأكثر، ضمن حدود زمنية وحجمية.
6. ينتج إجابة بلغة السؤال مع روابط قابلة للمراجعة وتقرير يوضح ما جرى فعليًا: عدد الاستعلامات، المصادر الفريدة، الصفحات التي قُرئ نصها، المحركات والمنصات، والتحذيرات.
7. في البحث العميق، يمرر المسودة على مراجعة ثانية للاتساق مع المصادر. هذه مراجعة من النموذج/الموفر نفسه وليست تحققًا مستقلًا من الحقيقة.

لا ينبغي تفسير اتفاق نتيجتين بحثيتين على أنه تصديق مستقل، ولا اعتبار عينة من التعليقات ممثلة لكل المستخدمين.

## 2. المصادر والحدود

| المصدر | ما يستخدمه Omarai | ما يلزم أو ما لا يمكن ضمانه |
| --- | --- | --- |
| صفحات الويب العامة | DuckDuckGo HTML وBing RSS، واستخراج نص الصفحات المتاحة | قد تمنع بعض المواقع القراءة أو لا تظهر في نتائج البحث؛ لا يتم تجاوز تسجيل الدخول أو الجدران المدفوعة |
| الأخبار الحديثة | Google News RSS بالإضافة إلى البحث العام | التاريخ الذي يظهر في موجز البحث قد لا يكون تاريخ نشر الصفحة الأصلية؛ يجب فتح المصدر والتحقق |
| Reddit | موجز البحث العام RSS | قد يُحجب أو يُقيَّد أحيانًا؛ يمكن إعداد OAuth لطلب API رسمي عند توفر وصول مسموح |
| Bluesky | واجهة البحث العامة للمنشورات | بحث عام وليس بيانات خاصة أو رسائل مباشرة |
| Instagram | صفحات عامة مفهرسة؛ وموصل Graph API للوسوم العامة عند إعداده | واجهة الوسوم الرسمية ليست بحثًا شاملًا في كل المنشورات، وتتطلب حسابًا وصلاحيات وموافقة/ميزات مناسبة وحدود استخدام |
| Facebook | صفحات عامة مفهرسة؛ وموصل مباشر لصفحات محددة صراحةً عند إعداده | الموصل المباشر ليس بحثًا عالميًا في Facebook؛ يعمل فقط على Page IDs يمكن للرمز والصلاحيات قراءتها |
| X | صفحات عامة مفهرسة؛ وواجهة البحث الحديث الرسمية عند إعداد Bearer Token | يتطلب وصول API مناسبًا، ونطاق البحث والحدود تابعان لخطة X |
| YouTube | صفحات الفيديو العامة المفهرسة؛ وYouTube Data API عند إعداد المفتاح | الواجهة الرسمية لها حصص استخدام، وقد لا تعيد كل الفيديوهات |
| TikTok | الصفحات العامة التي تظهر في محركات البحث | لا يدّعي Omarai أنه يملك بحثًا رسميًا شاملًا في TikTok. أدوات Research API تتطلب الأهلية والموافقة البحثية، وهي ليست واجهة عامة تلقائية للاستخدام التجاري |

## 3. تشغيل الطبقة التوليدية

يقرأ Omarai مفتاح النموذج من متغيرات بيئة Termux. افتراضيًا يستخدم نموذج NVIDIA Nemotron 3 Ultra (المجاني) لتخطيط البحث، وGoogle Gemma 4 31B Instruct (المجاني) لصياغة الإجابة ومراجعة الاتساق الثانية، مع الرجوع إلى `openrouter/free` إذا أخفق النموذج المحدد. هذا يقلل تغيير النموذج عشوائيًا بين الطلبات، لكنه لا يضمن استجابة كل موفر أو إجابة صحيحة. المفتاح يتيح تخطيط البحث والإجابة التوليدية والمراجعة الثانية. لا تحفظه داخل مستودع GitHub أو ملف HTML أو المحادثة.

```bash
read -r -s -p "OpenRouter API key: " OPENROUTER_API_KEY
printf '\n'
export OPENROUTER_API_KEY
```

يمكن تغيير موفر النموذج المتوافق مع OpenAI عبر `OMARAI_LLM_BASE_URL`. اضبط `OMARAI_PLANNER_MODEL` و`OMARAI_ANSWER_MODEL` و`OMARAI_REVIEW_MODEL` لتغيير الأدوار كلٌ على حدة، أو `OMARAI_LLM_MODEL` لتطبيق نموذج واحد على الأدوار التي لم تُحدد لها قيمة منفصلة، و`OMARAI_LLM_FALLBACK_MODEL` لتغيير النموذج الاحتياطي. توافر النماذج المجانية وحدودها يتغير؛ لذلك لا يفترض التطبيق أن النموذج مجاني دائمًا أو أن الطلب سينجح كل مرة.

## 4. إعداد الموصلات الرسمية الاختيارية

نفّذ فقط الأجزاء التي تملك بيانات اعتمادها وصلاحيات استخدامها. الأوامر أدناه تطلب السر دون إظهاره أثناء الكتابة، لكنها تبقيه في بيئة جلسة Termux الحالية حتى توقف الخادم أو تغلق الجلسة.

### Reddit OAuth

يتطلب بيانات تطبيق Reddit مع وصول API مسموحًا وفق شروط Reddit:

```bash
read -r -s -p "Reddit client ID: " REDDIT_CLIENT_ID; printf '\n'; export REDDIT_CLIENT_ID
read -r -s -p "Reddit client secret: " REDDIT_CLIENT_SECRET; printf '\n'; export REDDIT_CLIENT_SECRET
read -r -p "Reddit User-Agent: " REDDIT_USER_AGENT; export REDDIT_USER_AGENT
```

عند ضبط هذه القيم، يجرّب Omarai OAuth API. إن تعذر العثور على نتائج عبر API، فقد يحاول موجز البحث العام كبديل؛ ولا يعني ذلك أن البديل مضمون.

### Instagram Graph API — وسوم عامة

يتطلب Instagram User ID ورمز وصول صالحًا، مع الأذونات/الميزات اللازمة في تطبيق Meta. يقتصر الموصل على بحث الوسوم وجلب عينة من الوسائط العامة الحديثة؛ لا يصل إلى الحسابات الخاصة ولا يبحث كل Instagram.

```bash
read -r -p "Instagram professional user ID: " INSTAGRAM_USER_ID; export INSTAGRAM_USER_ID
read -r -s -p "Instagram access token: " INSTAGRAM_ACCESS_TOKEN; printf '\n'; export INSTAGRAM_ACCESS_TOKEN
```

يمكن ضبط إصدار Graph API الذي يطابق تطبيقك عبر `META_GRAPH_VERSION`. يبدأ Omarai بوسم واحد في الطلب لتقليل استهلاك حصة الوسوم؛ قد يظل الموصل يرفض الطلب إذا لم تكن الصلاحيات أو الحصة أو نسخة API مناسبة.

### Facebook Pages — صفحات محددة فقط

حدّد الصفحات التي لديك وصول مصرح بها. لا تضع رمزًا عامًا أو تحاول استخدام رمز لا يملك صلاحية الوصول للصفحة:

```bash
read -r -s -p "Facebook Page access token: " FACEBOOK_PAGE_ACCESS_TOKEN; printf '\n'; export FACEBOOK_PAGE_ACCESS_TOKEN
read -r -p "Authorized Page IDs, comma-separated: " FACEBOOK_PAGE_IDS; export FACEBOOK_PAGE_IDS
```

يقرأ الموصل أحدث منشورات الصفحات المحددة وعينة محدودة من التعليقات العامة التي تسمح بها الصلاحيات. قد تفشل قراءة المنشورات أو التعليقات إذا كانت صلاحيات التطبيق لا تسمح بها.

### X وYouTube

```bash
read -r -s -p "X API bearer token: " X_BEARER_TOKEN; printf '\n'; export X_BEARER_TOKEN
read -r -s -p "YouTube Data API key: " YOUTUBE_API_KEY; printf '\n'; export YOUTUBE_API_KEY
```

يجب أن يكون رمز X مرتبطًا بخطة وصول تشمل نقطة البحث المستخدمة. مفتاح YouTube يحتاج إلى مشروع Google Cloud تم تفعيل YouTube Data API فيه، ويخضع للحصة. لا يضمن وجود المفتاح أن الحساب يملك كل الصلاحيات أو حصة كافية.

### البدء بعد الإعداد

بعد إعداد أي متغيرات اختيارية تريدها، ابدأ الخادم في **جلسة Termux نفسها**:

```bash
python -m cli.omarai serve
```

افتح `http://127.0.0.1:8765` للمحادثة البحثية و`http://127.0.0.1:8765/api/health` لحالة الإعداد. تقرير الصحة يذكر ما إذا كانت المتغيرات موجودة فقط؛ ولا يمكنه التأكد من صلاحيتها حتى يجرب الموصل طلبًا حقيقيًا.

## 5. قراءة الأدلة والتحقق منها

- افتح المصادر الأساسية واقرأ السياق الكامل قبل اتخاذ قرار تجاري أو قانوني أو طبي.
- المنشور أو التعليق قد يكون ساخرًا أو قديمًا أو ترويجيًا أو خارج السياق. يوضح Omarai المصدر والنص المتاح، لكنه لا يثبت هوية الكاتب أو صحة كلامه.
- لا تستخدم بيانات شخصية غير لازمة، ولا تجمع محتوى خاصًا أو تتجاوز شروط أي منصة.
- لا يرسل Omarai رسائل أو يتواصل مع أصحاب الحسابات تلقائيًا. أي تواصل أو إجراء خارجي يجب أن يبقى بقرار بشري ومراجعة منفصلة.
